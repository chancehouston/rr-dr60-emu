# Contract: C API (`rr_dr60_ffi` 0.1.0, header `rr_dr60.h`)

This is a SemVer surface, versioned in lockstep with `rr_dr60` (FR-023, FR-024). The header is generated by cbindgen and committed. The shape below is normative; cbindgen output must match it.

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

#define RR_DR60_VERSION_MAJOR 0
#define RR_DR60_VERSION_MINOR 1
#define RR_DR60_VERSION_PATCH 0

typedef enum RrDr60Status {
    RR_DR60_STATUS_OK                    = 0,
    RR_DR60_STATUS_NULL_POINTER          = 1, /* a required pointer was NULL */
    RR_DR60_STATUS_UNSUPPORTED_HOST_RATE = 2, /* host_rate_hz not supported */
    RR_DR60_STATUS_INVALID_ARGUMENT      = 3, /* bad tap value, bad struct_size, partially overlapping buffers */
    RR_DR60_STATUS_INTERNAL_ERROR        = 4, /* a caught panic; the handle is poisoned until reset/reconfigure */
} RrDr60Status;

typedef enum RrDr60Tap {
    RR_DR60_TAP_AFTER_RECORD   = 0,
    RR_DR60_TAP_AFTER_PLAYBACK = 1,
} RrDr60Tap;   /* passed as uint32_t inside RrDr60Settings and validated */

typedef struct RrDr60Settings {
    uint32_t struct_size;            /* = sizeof(RrDr60Settings); allows the struct to grow later */
    uint32_t host_rate_hz;
    bool     record_stage_enabled;
    bool     playback_stage_enabled;
    uint32_t tap;                    /* RrDr60Tap */
    uint64_t seed;
} RrDr60Settings;

typedef struct RrDr60Pipeline RrDr60Pipeline;   /* opaque */

/* Defaults for host_rate_hz (not validated). Never fails. */
RrDr60Settings rr_dr60_settings_default(uint32_t host_rate_hz);

RrDr60Status rr_dr60_create(const RrDr60Settings *settings, RrDr60Pipeline **out_pipeline);
void         rr_dr60_destroy(RrDr60Pipeline *pipeline);              /* NULL is a no-op */

/* Real-time safe. input == output (in place) is allowed; any partial overlap is INVALID_ARGUMENT.
   frames == 0: both pointers may be NULL, and the call returns OK. */
RrDr60Status rr_dr60_process(RrDr60Pipeline *pipeline, const float *input, float *output, size_t frames);

RrDr60Status rr_dr60_latency_samples(const RrDr60Pipeline *pipeline, uint32_t *out_samples);
RrDr60Status rr_dr60_reset(RrDr60Pipeline *pipeline);                /* real-time safe */
RrDr60Status rr_dr60_reconfigure(RrDr60Pipeline *pipeline, const RrDr60Settings *settings); /* not RT-safe */

/* Static NUL-terminated string, e.g. "0.1.0". Never NULL; do not free. */
const char  *rr_dr60_version_string(void);
```

## Rules

1. **Errors are values (FR-024).** No function aborts, unwinds into C, or calls `exit`. Every entry point body runs inside `catch_unwind`. A caught panic returns `INTERNAL_ERROR` and poisons the handle. The `std` allocator's out-of-memory handler can still abort the process during `create` or `reconfigure`. This is documented as the only exception, and it can only happen outside real-time calls.
2. **Failed calls change nothing.** On any non-OK status, `*out_*` parameters are left untouched and the pipeline state is unchanged (except poisoning).
3. **Ownership.** The caller owns the buffers. The library never keeps a buffer pointer after a call returns. `destroy` frees the handle; using the handle after `destroy` is undefined behavior (documented in the header).
4. **Threading.** A handle must not be used by two threads at once. Separate handles are independent.
5. **ABI stability.** `RrDr60Settings` only grows at the end. `struct_size` must be at least the v0.1 size, or the call returns `INVALID_ARGUMENT`. New status codes and tap values are only appended.
6. **Parity (FR-023).** For any settings and input, `rr_dr60_process` output is bit-identical to `Pipeline::process`. The harness test `ffi_parity` checks this.
7. **Unsafe hygiene.** Every `unsafe` block in `rr_dr60_ffi` has a `// SAFETY:` comment. Pointer and length pairs are turned into slices only after null and overlap checks.

## Error-path tests (`ffi_parity`, C `smoke.c`)

| Call | Input | Expected |
|---|---|---|
| `rr_dr60_create` | `settings = NULL` | `NULL_POINTER` |
| `rr_dr60_create` | `host_rate_hz = 22050` | `UNSUPPORTED_HOST_RATE`, `*out` untouched |
| `rr_dr60_create` | `tap = 7` | `INVALID_ARGUMENT` |
| `rr_dr60_create` | `struct_size = 4` | `INVALID_ARGUMENT` |
| `rr_dr60_process` | `pipeline = NULL` | `NULL_POINTER` |
| `rr_dr60_process` | `frames = 64`, `input = NULL` | `NULL_POINTER` |
| `rr_dr60_process` | `frames = 0`, both NULL | `OK` |
| `rr_dr60_process` | `output = input + 1` | `INVALID_ARGUMENT` |
| `rr_dr60_process` | `output = input` | `OK`, same as the copy-based result |
| `rr_dr60_reconfigure` | an unsupported rate | `UNSUPPORTED_HOST_RATE`, old configuration still works |
| `rr_dr60_destroy` | `NULL` | no-op |
