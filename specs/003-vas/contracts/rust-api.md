# Contract: Rust public API changes (`rr_dr60` 0.2.0 → 0.3.0)

This is a delta against [002's Rust API contract](../../002-agc/contracts/rust-api.md). Anything not listed is unchanged. The default output length changes (VAS on, drop mode), so the 0.x minor version goes up. Every new public item gets rustdoc that cites its FR and A-IDs.

```rust
/// Where the pipeline output is taken.
#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash, Default)]
#[non_exhaustive]
pub enum Tap {
    AfterAgc,
    AfterRecord,
    /// NEW. After signal-chain stage 5 (VAS). Stage 10 is not run (spec 003 FR-003).
    AfterVas,
    #[default]
    AfterPlayback,
}

/// NEW. What happens to audio while VAS is paused (spec 003 FR-004).
#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash, Default)]
#[non_exhaustive]
pub enum VasMode {
    /// Removed from the output, so the output gets shorter. Device behavior (S-001, A-008).
    #[default]
    Drop,
    /// Replaced by digital silence, so the output keeps the input's length. An emulator
    /// option for real-time hosts, not a device behavior.
    Mute,
}

/// NEW. Voice Activated System, signal-chain stage 5 (spec 003).
/// Modeled on the owner's manual (S-001) and assumed values (A-008, A-021 – A-025).
#[derive(Clone, Copy, Debug, PartialEq)]
#[non_exhaustive]
pub struct VasSettings {
    /// On (true, default: the device has no VAS switch, S-001, A-008) or bypassed.
    pub enabled: bool,
    /// Drop (default) or mute.
    pub mode: VasMode,
    /// Microphone sensitivity level, 1 ..= 5. Default 3 (S-001, A-021). In this version it
    /// moves only the VAS threshold: 3 dB per level, higher levels record quieter sounds (A-022).
    pub sensitivity: u8,
    /// Threshold at sensitivity level 3, dBFS (sine peak, AES17). Default −18.0 (A-022).
    /// Range −60.0 ..= 0.0.
    pub threshold_dbfs: f32,
    /// Hang time in ms. Default 1000.0 (A-023). Range 50.0 ..= 10000.0.
    pub hang_ms: f32,
    /// Onset time in ms (lost word onsets). Default 20.0 (A-024). Range 0.0 ..= 200.0.
    pub onset_ms: f32,
}

impl VasSettings {
    /// The assumed device values.
    pub const DEVICE: Self = /* enabled: true, mode: Drop, sensitivity: 3, threshold_dbfs: -18.0,
                                hang_ms: 1000.0, onset_ms: 20.0 */;
}
impl Default for VasSettings { /* DEVICE */ }

pub struct Settings {
    // … 001 and 002 fields unchanged …
    /// NEW. Signal-chain stage 5 settings. Default VasSettings::DEVICE.
    pub vas: VasSettings,
}

/// NEW. The result of one processing call (spec 003 FR-004, FR-005).
#[derive(Clone, Copy, Debug, PartialEq, Eq, Default)]
#[must_use]
#[non_exhaustive]
pub struct BlockInfo {
    /// Output samples written to the start of the output buffer (≤ input length).
    pub produced: usize,
    /// VAS events generated by this block.
    pub events: usize,
    /// VAS is paused at the end of the block.
    pub paused: bool,
}

/// NEW. A splice (drop mode) or a muted region (mute mode) (spec 003 FR-005).
#[derive(Clone, Copy, Debug, PartialEq, Eq, Default)]
#[non_exhaustive]
pub struct VasEvent {
    /// Drop: stream output index of the first sample after the splice.
    /// Mute: stream output index of the region's first muted sample.
    pub output_position: u64,
    /// Drop: host input samples removed at this splice. Mute: region length.
    pub input_length: u64,
}

impl Pipeline {
    /// CHANGED: returns BlockInfo instead of (). In drop mode only output[..produced] is
    /// written; the rest of `output` is left unchanged.
    pub fn process(&mut self, input: &[f32], output: &mut [f32]) -> Result<BlockInfo, Error>;

    /// CHANGED: returns BlockInfo instead of (). The block's output is buffer[..produced].
    pub fn process_in_place(&mut self, buffer: &mut [f32]) -> BlockInfo;

    /// NEW. As `process`, and writes the first `events.len()` events, in order. BlockInfo.events
    /// counts all of them, so `info.events > events.len()` means some were not written.
    /// Real-time safe.
    pub fn process_with_events(
        &mut self,
        input: &[f32],
        output: &mut [f32],
        events: &mut [VasEvent],
    ) -> Result<BlockInfo, Error>;

    /// NEW. An events-slice length that is always enough for a block of `frames` input samples
    /// with the current settings (R-07). Computed without overflow. Never allocates.
    pub fn max_events(&self, frames: usize) -> usize;
}

#[non_exhaustive]
pub enum Setting {
    // … AGC variants unchanged …
    /// NEW. `vas.sensitivity`, 1 ..= 5.
    VasSensitivity,
    /// NEW. `vas.threshold_dbfs`, −60.0 ..= 0.0 dBFS.
    VasThresholdDbfs,
    /// NEW. `vas.hang_ms`, 50.0 ..= 10000.0 ms.
    VasHangMs,
    /// NEW. `vas.onset_ms`, 0.0 ..= 200.0 ms.
    VasOnsetMs,
}
```

## Rules

1. **Validation order**: host rate → AGC fields → VAS fields, in struct order (`sensitivity`, `threshold_dbfs`, `hang_ms`, `onset_ms`).
2. **Fixed length when VAS does not drop**: when VAS is bypassed, in mute mode, or not reached by the tap, `produced == input.len()` for every block, and `events == 0` unless in mute mode.
3. **Partition independence**: for any block partition, the concatenated `output[..produced]` slices, the event sequence and the final `paused` value are bit-identical (FR-014).
4. **In place**: `process_in_place` writes the block's output to `buffer[..produced]`. Samples past `produced` are unspecified.
5. **Re-exports**: `VasSettings`, `VasMode`, `BlockInfo` and `VasEvent` are re-exported from the crate root.
6. **Doc-test (SC-001)**: the `VasSettings` rustdoc has an example that bypasses VAS, switches to mute mode, sets sensitivity 5, and reads `produced` and events.
