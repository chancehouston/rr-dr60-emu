# Data model: the non-speech reshaping report

No stored data, no C struct, no library type. Everything below lives in `rr_dr60_harness::nonspeech_checks`.

- **`Stimulus`** `{ id: &str (a35, a50, a55, b, c, d, e, f, g, h), seed: u64, level_dbfs: f64, params }`; `fn samples(rate) -> Vec<f32>` (12 s at the host rate). The noise core: uniform `Pcg32(seed)` noise through the Kaiser low-pass (β = 8, about 10 ms, edges 0 and 2900 Hz, detmath), scaled so the AES17 RMS over the whole stimulus equals `level_dbfs`; (b) × `1 + 0.5·sin(2π·4t)` then rescaled; (c) × the three-sine envelope then rescaled; (d) bursts: a seeded sequence of (gap s, duration s, level dBFS) rounded to whole samples at 6 kHz, each burst the noise × sin²(π·n ÷ dur) scaled to its own RMS; (e) the Kellet pink filter on the low-passed noise, rescaled; (f) zeros; (g) `stimulus::voiced(rate, 12.0, -20.0, seed)`; (h) the (a35) noise through a biquad resonator (750 Hz, Q 1.8, unity peak), rescaled to −35 dBFS.
- **`Configuration`** `{ id: &str (C0 … C7), name: &str (configs::settings name), tap: Tap, note: &str }`; `fn settings(rate) -> Settings`.
- **`ReaderOptions`** `{ prominence: bool, pre_emphasis: bool, lag_max: usize, include_flush: bool, reset_state: bool }`; `PRODUCTION = { true, true, 100, false, true }`.
- **`Measures`** `{ level_dbfs: f64, peaks: Option<f64>, movement_hz: Option<f64>, periodicity: Option<f64>, periodic_fraction: Option<f64>, lag_stable: Option<f64>, mod_share: Option<f64>, flux_db: Option<f64>, active: usize, frames: usize }`; `None` prints "—".
- **`Cell`** `{ stimulus, configuration, rate, latency, measures, input_own: Option<Measures> (C0 rows) }`.
- **`Table`** `{ rate, cells: Vec<Cell> }`; `fn compute(rate, block: usize, options) -> Table`; `fn text(&self) -> String`.
- **The canonical text**: line 1 `rr_dr60 non-speech reshaping report v1` (no library version); the stimulus block (one line per stimulus: id, seed, level, params); the configuration block (id, name, tap, latency at this rate); the definitions block (the nine definitions with their constants: frame 120, settle 0.5 s, active −75 dBFS, LPC order 8, pre-emphasis 0.9, grid 10 Hz, search 200 – 2300 Hz, prominence 3 dB over ±300 Hz, width ≤ 300 Hz, lags 20 – 100, r > 0.5, lag ±2 at r > 0.35, Hann DFT 0.5 – 25 Hz, share 2 – 8 Hz, span ≥ 90 % active); the floors block (C0's movement, lag-stable and flux on (a35)); then `rate 6000` and a fixed-width table `stim cfg level active peaks move r rfrac lagst share flux` with precisions 0.01 dB / integer / 0.001 / 0.1 Hz / 0.001 / 0.001 / 0.001 / 0.001 / 0.01 dB; then `rate 44100`, `rate 48000`. LF line ends, no trailing spaces (the `.txt` exemption in `.editorconfig` applies to goldens).
- **The golden**: `crates/rr_dr60_harness/golden/nonspeech-v1.txt`; the SHA-256 of its bytes pinned in `golden_nonspeech.rs`; the bless writes the text and asserts D5's partition identity and D6's checks at the three rates.
- **`Check`** (in the tests): `{ id: "D6 i" …, requirement: "FR-006", figure, bound, margin }` printed through `report::print` as the harness's other checks are.
