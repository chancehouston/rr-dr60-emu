What the feature set anchors

  • Recorder front: LCD timer and level, persistent Stop, playback, 60-minute / 99-item memory, and device controls.
  • Inside: stage status and evidence, path-specific values, empty sockets for stages not modeled, tap-to-inspect cards, and a flat text-list entry.
  • Investigation: large REC, MARK, and “Question asked here”; labelled µT, g, and hPa readings; silent operation; one cursor across audio and sensor tracks.
  • Review marks remain user-authored. Alignment is an indicated time window; the UI makes no claim about what the audio contains.

Where the dossier proposals change

The 1.0 engine has a fixed 15-stage chain. Reverb, added modules, insertion, reordering, and removal are not represented as 1.0 functionality. Stage badges use the current counts: 13 assumed, 2 not modeled, 0 sourced, and 0 checked against a real unit. Sensor readings are illustrative UI data only; the brass, glow, and texture are static decoration.
