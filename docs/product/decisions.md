# Product decisions

A log of product decisions with the alternatives considered, the evidence, and the cost of reversing. Add a row when a decision is made or changed. Engineering decisions live in the specs.

The current summary of all product decisions is [brief.md](brief.md). A row marked **Superseded** no longer holds; it names the row or brief section that replaced it. Rows are never deleted.
